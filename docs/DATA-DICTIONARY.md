# 补植验收册数据字典

## 来源文件

| 字段 | 定义 |
|---|---|
| 街段验收单 | 文本主键，保留前导零。跨业务键不汇并记录。 |
| 修订号 | 正整数。最高版优先；最高同版字段冲突或存在同版、更新版的未采信记录时隔离，旧版无法接替。 |
| 提交时间 | ISO 8601，必须带 UTC 偏移量。标准化后展示 UTC。 |
| 原始备注 | 可空，允许引号内换行。 |
| 验收日、观察期天数、单株款元、逐株事件 | 必填字段。多项字段用半角分号隔开，显式空集合用 `无`。 |

识别 `UTF-8`、UTF-8 BOM 与独立的 `GB18030` 文件。`业务编号`、`版本`、`更新时刻`、`备注` 为旧版表头别名。新旧名同时出现会被拒绝。`-`、`N/A`、`NULL`、`未知` 和空串均按必填值缺失处理。物理行号指 CSV 逻辑记录起始行。

## 计算字段

事件写 `树号:日期:种植或死亡或补植或巡检存活`。验收日之后的状态不参与本批。

补植从当天重置观察期；巡检日距补植达到期间要求才算通过。按唯一树号结算，款项按分取半入。

数值在服务端以十进制定点方式计算，对外按字符串传输。单文件上限 128 KiB，复合字段最多 240 个项目，个别字段还有业务上限。格式无法恢复的 CSV 整批拒绝，列数、缺字段、来源冲突和业务条件错误逐条隔离。

## 复算与外部清单

外部清单包含 `街段验收单` 和 `外部记录值(元)`，允许省略不在对账范围内的键。同一键重复会拒绝该清单。结果数值单位为 **元**。差值按本次复算减外部记录，缺一侧时差值计算以 0 占位并保留缺失原因。

同一对输入字节与规则版本生成同一批次，导出包含两个文件摘要、证据行、单边差异和复核修订记录。复核保存前检查当前版本，在有隔离、差异或退回时必须填写意见。

## 苗批核销

### 苗批进场账

| 字段 | 定义 |
|---|---|
| 苗批号 | 文本主键，同批重复登记整账拒绝（`LOT_CONFLICT`）。 |
| 树种 | 与领用单、补植株的树种一致才可落批。 |
| 进场日 | `YYYY-MM-DD`。晚于补植日的苗批不得追溯扣减该树位。 |
| 进场数量 | 正整数，核销后余量不得为负。 |

### 领用册

字段固定为 `领用单号,修订号,提交时间,街段验收单,树位号,树种,数量,原始备注`。一张领用单可含多个树位、跨多个街段。坏行（列数、修订号、偏移时间、数量越界）逐条隔离；同一领用单按修订号整体仲裁：旧版抑制（`SUPERSEDED`），同版同内容重传只保留最早行（`EXACT_DUP`），同版同树位内容冲突整单隔离（`REQ_CONFLICT`）。

### 核销规则

1. 只有采信街段中存在对应 `(街段验收单, 树位号)` 补植事实的领用行才可核销；街段未采信（`UNKNOWN_KEY`）、无补植依据（`NO_BASIS`）、树种不符（`SPECIES_MISMATCH`）的树位直接挂起。
2. 同一补植树位被多张领用单认领时，竞争行全部挂起（`REQ_DUP_TREE`），交人工裁决，不自动扣减。
3. 可核销行按补植日、街段、领用单、树位的确定顺序，在同树种、进场日不晚于补植日且仍有余量的苗批中按 FIFO 落批；一次申领可拆到多个苗批。
4. 欠苗策略二选一：
   - `partial` 按余量核销：能结多少结多少，同一领用单拆成已核销与挂起欠苗；
   - `whole` 整张退回：单内任一树位无法足额则整单不扣、余量回滚，已补的树等苗，领用单保持完整。
5. 任一验收批次存在挂起树位即标记 `暂缓签收`，签收底稿拒绝「确认」（`WRITEOFF_HELD`），须先清挂起或改策略重跑。
6. 同一批输入（来源、外部账、苗批账、领用册、策略）生成同一批次指纹；重跑复用同一条批次记录，核销结果与苗批余量逐字节一致，不重复扣减。
7. 数量闭合：申领总量 = 已核销 + 挂起；苗批已核销合计 = 已核销总量；所有苗批余量 ≥ 0，任一不闭合直接报错不出结果。
